## 📌 Descripción del Proyecto

**Ejercicio2** es un programa desarrollado en Java que permite al usuario ingresar un **número de dos cifras** y muestra dicho número invertido.

El proyecto aplica operaciones matemáticas básicas para separar y reorganizar los dígitos de un número entero, siendo un ejercicio ideal para fortalecer la lógica de programación.

## ▶️ Funcionamiento del Programa

```java
1. Usuario ingresa un número de dos cifras
2. Programa separa las cifras:
   - Decenas → división entre 10
   - Unidades → módulo %
3. Se invierten las cifras
4. Se muestra el número invertido en pantalla
```
