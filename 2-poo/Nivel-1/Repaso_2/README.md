## 📌 Descripción del Proyecto

Proyecto de gestión de biblioteca que permite:
- ✅ Registrar libros con ISBN, título, autor y número de páginas
- ✅ Almacenar información de múltiples libros
- ✅ Utilizar programación orientada a objetos

## 🏫 Clase: Libro

| Tipo | Atributos/ Métodos |
|------|-------------------|
| **Atributos** | ISBN, Titulo, Autor, Paginas |
| **Constructor** | Libro(int ISBN, int Paginas, String Titulo, String Autor) |
| **Getters** | getISBN(), getTitulo(), getAutor(), getPaginas() |
| **Setters** | setISBN(), setTitulo(), setAutor(), setPaginas() |
| **Método** | toString() - Representación textual del libro |
