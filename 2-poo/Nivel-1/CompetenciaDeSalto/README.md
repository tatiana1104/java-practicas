## 📌 Descripción del Proyecto

El proyecto **CompetenciaDeSalto** simula una **competencia de salto largo** con N atletas.

Cada atleta realiza **tres saltos**, cuyos valores se generan de forma aleatoria entre **250 cm y 450 cm**.

El programa muestra:
- ✅ Los saltos de cada atleta
- ✅ El promedio individual de cada atleta
- ✅ El promedio general de todos los saltos

## ▶️ Funcionamiento del Programa

```java
1. Usuario ingresa la cantidad de atletas
2. Para cada atleta se generan 3 saltos aleatorios
3. Se muestran las distancias de cada salto
4. Se calcula el promedio por atleta
5. Se calcula el promedio general de todos los saltos
```
