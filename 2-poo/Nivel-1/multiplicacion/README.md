## 📌 Descripción del Proyecto

El proyecto **Multiplicacion** es una aplicación de consola desarrollada en Java que permite ingresar **dos números enteros** y calcular su producto.

Este ejercicio está orientado a reforzar:
- ✅ Lógica básica de programación
- ✅ Uso de entrada por consola
- ✅ Organización del código mediante clases y métodos
- ✅ Principios iniciales de POO
