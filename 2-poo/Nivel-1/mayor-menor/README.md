## 📌 Descripción del Proyecto

El proyecto **MayorMenor** es una aplicación de consola desarrollada en Java que permite **determinar el número mayor y el número menor** entre tres valores ingresados por el usuario.

Este ejercicio refuerza:
- ✅ Uso de condicionales
- ✅ Comparaciones lógicas
- ✅ Programación Orientada a Objetos (POO)
