## 📌 Descripción del Proyecto

El proyecto **Análisis de Matrices Aleatorias** crea dos matrices bidimensionales de tamaño 3x5, las llena con números aleatorios entre 15 y 23, y realiza un análisis sobre ellas:

- ✅ En la matriz 1 se identifica el **valor menor** y su posición
- ✅ En la matriz 2 se identifica el **valor mayor** y su posición

Finalmente, el programa muestra los resultados por consola.

## ▶️ Funcionamiento del Programa

```java
// Pseudocódigo del funcionamiento
1. Crear dos matrices de tamaño 3x5
2. Llenar cada matriz con valores aleatorios (15-23)
3. Mostrar valores de cada matriz por consola
4. Buscar el menor valor en matriz 1 → guardar posición
5. Buscar el mayor valor en matriz 2 → guardar posición
6. Imprimir resultados finales con posiciones
```
