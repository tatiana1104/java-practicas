## 📌 Descripción del Proyecto

Este proyecto implementa un **sistema básico de gestión de notas** utilizando arreglos en Java.

Permite al usuario:
- ✅ Crear un arreglo de notas
- ✅ Ingresar valores válidos
- ✅ Obtener estadísticas (promedio, nota mayor, nota menor)
- ✅ Cantidad de notas por encima del promedio

El programa funciona mediante un **menú interactivo por consola**.
